# FormatusBar

* Class `FormatusBar` is a Widget providing formatting actions
* Each action is provided by a separate icon-button
* Actions can be condensed into groups
* `FormatusBar` requires the same `FocusNode` and
  `FormatusController` as the `TextField` itself
* buttons will be displayed active when all characters 
  in text selected inside `TextField` have the same format
